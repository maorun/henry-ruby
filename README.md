# Abenteuer von Henry und Ruby

Willkommen zu unserem kollaborativen Buchprojekt!  
Hier schreiben wir gemeinsam, unterstützt von GitHub Copilot, die Abenteuer von Henry (6 Jahre) und seiner kleinen Schwester Ruby (4 Jahre).  
Jedes Kapitel ist eine einzelne Markdown-Datei im Verzeichnis `chapters/`.

Neue Kapitel können einfach als Issue erstellt werden – Copilot hilft beim Fortführen der Geschichte!

## Verzeichnisstruktur

- `chapters/` – Enthält alle Kapitel als numerierte Markdown-Dateien.
- `.github/ISSUE_TEMPLATE/` – Enthält die Vorlage für ein neues Kapitel-Issue.
- `copilot-instructions.md` – Gibt Copilot Hinweise für die Fortsetzung der Story und den Stil.

Viel Spaß beim Mitschreiben!
